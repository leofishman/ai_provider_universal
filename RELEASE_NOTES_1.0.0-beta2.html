AI Provider: Universal 1.0.0-beta2

Changes since 1.0.0-beta1.

Highlights

  • No AI core patches required. Model IDs use a dot separator (server.model, smart routes route.<id>) and getConfiguredModels() returns a flat model_id => label map. AI settings and ai_search resolve Universal models out of the box (fixes #3611069 — “Universal | Array” in the embeddings engine select).
  • Content governance submodule (ai_provider_universal_governance): default Guardrail set attach, AI-origin provenance events, disclosure suffix / origin marker / fact-check and AI-likelihood Guardrail plugins, optional field-based disclosure UI, and starter recipes.
  • Scheduled content review (factcheck): scan profiles enqueue checks on node save; cron/queue runs them; optional content-review events for ECA/Workflow.

Upgrade notes (from beta1)

  1. Run database updates: drush updb (update 10102 renames model entity IDs from server__machine to server.machine and rewrites stored references in AI defaults, smart routes, router/factcheck settings, Search API embeddings engines, and usage counters).
  2. Clear caches: drush cr.
  3. If you previously applied the module’s recommended drupal/ai patches (optgroups / explode limit 2), you can remove them — they are no longer needed for this provider.
  4. Optional: enable ai_provider_universal_governance and review Configuration → AI → Providers → Universal → Content governance.

Changes

  • Flat model options with Server: model labels (no nested optgroups).
  • Model ID separator . instead of __ so AI core’s provider__model parsing stays correct.
  • Content governance design and implementation (Guardrails attach, provenance, disclosure, Art. 50–oriented docs).
  • Scan profiles for async content review (factcheck).
  • Docs: glossary, servers-and-models, smart routing, usage limits, content governance; README installation and config paths.
  • Spanish translations updated (main, router, factcheck); new ai_provider_universal_governance.es.po.

Requirements

  • Drupal 11.1+ / 12
  • AI ^1.3 (Guardrails API for governance features)
  • Key

Install: composer require 'drupal/ai_provider_universal:^1.0@beta'
